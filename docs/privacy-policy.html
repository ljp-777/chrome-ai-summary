AI 页面总结 隐私政策

最后更新：2026-06-03

「AI 页面总结」（以下简称「本扩展」）尊重您的隐私。本政策说明本扩展如何处理信息。

1. 我们不运营后端服务器

本扩展不在开发者服务器上存储、处理或传输您的数据。所有总结请求由您的浏览器直接发送至您自行配置的 AI API 地址（如 OpenAI、DeepSeek、火山方舟等）。

2. 本扩展可能访问的数据

  • 页面内容：仅在您主动触发「总结当前页面」或「总结选中文本」时，读取相应文字。
  • 剪贴板：仅在您主动粘贴、总结剪贴板或使用相关功能时读取，不会后台持续监听。
  • API 配置：API Key、模型名等保存在 Chrome 本地/同步存储（chrome.storage.sync）中。

3. 数据去向

  • 您选中的文字或页面正文会作为请求内容发送到您配置的第三方 AI 服务。
  • 该第三方服务的隐私政策由对应服务商负责，请自行查阅。
  • 开发者无法访问您的 API Key 或总结内容。

4. 我们不收集的内容

  • 不收集浏览历史、账号信息、设备标识
  • 不使用分析/追踪 SDK
  • 不向开发者服务器上传任何用户数据

5. 权限说明

  • storage：保存 API 配置
  • activeTab / scripting：在当前页面注入总结面板
  • contextMenus：右键菜单快捷入口
  • clipboardRead：读取您主动总结的剪贴板文字
  • <all_urls>：在任意网页提供划词总结（除 Chrome 限制页面外）

6. 数据删除

卸载扩展或在选项页清除配置即可删除本地保存的 API Key 与设置。

7. 政策变更

如有更新，将在本项目仓库中修订本页面。
